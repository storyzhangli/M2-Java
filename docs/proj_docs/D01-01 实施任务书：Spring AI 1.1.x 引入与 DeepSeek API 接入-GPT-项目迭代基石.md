### 2.2 三个必须厘清的机制

第一，依赖引入不等于 API 已接通。

引入 Starter 后，Spring Boot 可以根据配置自动创建模型相关 Bean；只有实际发送请求并收到 DeepSeek 的有效响应，才能证明远端 API 通信成功。

第二，模拟模式不等于模拟 API 鉴权。

模拟模式应绕过真实模型调用，并返回可预测的模拟结果。占位密钥只用于避免真实凭据进入代码仓库，不能用来验证 DeepSeek 的鉴权能力。

第三，配置成功不等于真实调用成功。

真实调用还取决于密钥有效性、模型名称、网络访问、服务端状态、账户额度以及请求参数。上述故障应与本地代码编译错误分开诊断。

      chat:

          model: ${DEEPSEEK_MODEL:deepseek-flash}

app:
  ai:
    mode: ${AI_MODE:mock}
