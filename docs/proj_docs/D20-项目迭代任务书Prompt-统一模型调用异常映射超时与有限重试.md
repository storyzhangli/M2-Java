## 4. 异常分类与统一映射要求

根据现有项目的错误码体系扩展，禁止另建一套冲突的错误响应。内部异常分类至少评估以下类型：

| 分类 | 典型情况 | 默认重试策略 |
|---|---|---|
| 参数/请求错误 | 请求字段非法、模型参数无效、请求体不符合约定 | 不重试 |
| 鉴权/授权失败 | API Key 无效、无权限 | 不重试 |
| 模型/资源不存在 | 模型名错误、端点或资源不存在 | 不重试 |
| 业务拒绝/内容策略拒绝 | 服务端明确拒绝内容或请求 | 不重试；按实际供应商语义映射 |
| 限流 | HTTP 429 / 供应商限额响应 | 仅在确认为可恢复限流、遵守 `Retry-After`、预算和总 Deadline 时有限重试；额度耗尽/账户欠费等永久情况不重试 |
| 上游暂时不可用 | 经核实可恢复的 502/503/504 等 | 可有限重试；必须评估请求可能已被处理及重复计费风险 |
| 建连失败 | DNS、连接拒绝、连接建立失败 | 仅对能够确认请求尚未发送的情况考虑重试；DNS 永久配置错误不应循环 |
| 连接/读取超时 | Connect timeout、response/read timeout | 分开分类。建连前超时可评估重试；请求发送后响应超时具有结果不确定性，默认不自动重试，除非有幂等保障或明确策略 |
| 响应解析/结构校验失败 | JSON 解析、结构化输出校验失败 | 默认不做传输层重试；如需模型纠正重试，必须作为独立业务策略设计，设置单独上限和成本预算 |
| 客户端取消/断开 | 请求取消、SSE 客户端断开 | 不重试，及时取消下游订阅/资源 |
| 未知异常 | 无法归类的运行错误 | 默认不重试，记录脱敏诊断信息 |

实现时要区分内部异常、日志诊断信息和对外错误响应。不得将 API Key、完整 Prompt、模型原始堆栈或敏感用户输入返回给客户端。对外 HTTP 状态码和错误码优先兼容现有契约；有冲突时先列出兼容方案，不得静默改变旧接口。

内部错误对象/上下文可按现有设计承载：错误分类、稳定错误码、供应商、模型、HTTP 状态、是否可重试、实际尝试次数、请求关联 ID、耗时和安全的诊断摘要。只保存当前链路需要的数据，不为字段齐全而过度设计。

## 5. 超时与有限重试策略

### 5.1 超时配置

至少区分并确认：

- 连接建立超时（Connect Timeout）；
- 响应/读取超时（Response / Read Timeout）；
- 单次模型尝试的最大执行时间；
- 整个模型调用的总 Deadline（包含所有尝试与退避）；
- 流式首包等待/流间隔或空闲超时（仅在当前客户端确实支持且场景适用时配置）。

配置必须外部化、具有合理默认值和范围校验，并在启动配置或测试中能验证生效。数值先结合当前模型、历史实测、接口 SLA 和现有调用方式确定；没有数据时记录为初始配置，不宣称为性能最优值。不要直接照搬 Boot 全局 HTTP 客户端配置，必须确认 Spring AI DeepSeek 客户端实际采用的 HTTP client / request factory。

### 5.2 重试规则

- 只允许一个明确的重试责任层。若 Spring AI 1.1.8 内置重试已满足需要，优先正确配置并在必要处增加分类；若无法满足，再说明为何需要应用层策略。
- 默认采用保守的小上限；建议先评估最多 2 次总尝试（1 次重试），确有依据时才提高，绝不使用无界重试。
- 对可重试错误使用有上限的退避；若实现支持，加入随机抖动（jitter）；尊重 `Retry-After`，同时受总 Deadline 限制。
- 禁止对 400、401、403、404、非法模型/参数、永久账户额度问题、内容拒绝、客户端取消和未知异常盲目重试。
- 对请求已发送后的 Read Timeout、响应中断和 5xx，评估“服务端可能已处理、响应丢失、重复产生 Token 费用”的风险；不能证明安全时默认不重试，并在结构化记录中说明。
- 禁止多层重试叠加。最终最大请求次数必须可计算、可测试、可观测。
- 对流式调用：客户端取消时立即停止；一旦已有内容片段发送给客户端，不得自动从头重放并把重复内容拼接给客户端。首个内容发出前是否允许重试，也必须评估上游是否可能已经处理请求及重复计费风险；无法证明安全时不重试。
- 不将模型 JSON 修复、Prompt 重写等业务纠错行为混入底层 HTTP 重试策略。

### 5.3 预算与配置验收

输出配置表：配置名、默认值、单位、作用层、是否支持热更新、上限、配置来源及验证方法。任何具体属性名必须从 Spring AI 1.1.8、Spring Boot 3.5.16 及本项目实际客户端配置中核实，不得把其他版本属性直接复制过来。
