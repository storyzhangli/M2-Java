## 全程监督反馈体系（解决自律不足+表达偏弱）

### 1. 每日监督闭环

- **工具**：AI督学（豆包/通义千问）+ 付费打卡群（200元押金）
- **流程**：
  1. 早8:30：AI生成当日精确计划，打卡群发当日计划
  2. 每小时拍屏幕打卡，中途离开计时
  3. 晚20:00前：提交代码截图+口述录音+当日总结到打卡群
  4. AI评估当日完成率，低于80%自动发20元红包到群
- **表达训练强制**：每天口述任务必须脱稿、录音，时长达标，少一分钟补十分钟

### 2. 每周监督闭环

- 每周日晚：周度AI模拟面试（技术+项目），当场打分
- 低于60分：周日取消休息，全天补对应模块
- 连续两周低于70分：自动加100元押金，惩罚加倍

### 3. 阶段验收闭环

- 每个阶段最后1天：阶段总验收，口述+项目演示
- 验收不通过：下一阶段每天加练1小时，直到达标

### 4. 铁律惩罚机制

1. 当日任务完成率<80%：取消当晚娱乐，补完为止，发20元惩罚红包
2. 连续3天未打卡：自动加购1周一对一督学
3. 学习时间刷短视频/游戏：发现一次加练1小时算法
4. 90天内必须入职，绝不无限期脱产
