**Java → Java AI 工程师：90 天·每日 9 小时执行与监督计划**

**适用前提**：你能敲代码（这是最大资产），但自律性不足、技术表达不足、有 2.5 年空窗。所以本计划的核心不是“学多少”，而是**用外部强制结构替代自律，用可展示物替代“我学过”**。

---

### 一、总纲：三条不可违背的铁律

1. **只做一个项目**：制造业设备故障知识库 + 工单助手（公网可访问）。Java 复习、AI 学习、简历证据，全部挂在这一个项目上。任何“再开一个练手”的冲动一律禁止。
2. **从 D1 开始投简历**，绝不等到“学完”。投递是独立 KPI，与编码并行；空窗期只能用“近期在职/近期产出”来止血，不能用“学了更多”来解释。
3. **每天必须有可外部验证的交付物**（commit、部署链接、一篇笔记、一段录音）。自律性不足的人只能靠交付物驱动，不能靠状态驱动。

---

**最低可行日规则**：状态崩的那天，只做三件事——1 个 commit、5 份投递、1 条站会消息。保住链条不断，不自责不加时。

### 三、四层监督与反馈机制（逐级上，不要一次全开）

#### 第 1 层｜免费，D0 必须开通（解决 70% 问题）
1. **双人 22:00 站会**：互发「今日完成 / 明日计划 / 卡点」，缺席发红包 50 元。找不到人就找两个前同事轮流，或技术群结对。
2. **公开承诺**：GitHub README 写死 D30/D60/D90 三个日期与验收标准；掘金/知乎每周一更。有人看着就不好意思停。
3. **物理隔离**：编码时段去图书馆/自习室，不在卧室。环境线索比意志力可靠。
4. **KPI 看板**（一张表，只看数字不看感觉）：每日编码小时 / commit 数 / 投递数 / 面试数 / 评测集命中率。

#### 第 2 层｜押金制，第 2 周起生效
每周日 22:00 自检：**四条 KPI 任一当周累计为 0 → 向指定账户转 100 元（不可退回）**。钱不重要，痛感重要。

#### 第 3 层｜真人反馈，解决“技术表达不足”
- **每两周一次付费模拟面试**（在职工程师，200–400 元/次），从 **D14 就开始**，别等准备好。第一次一定很惨，目的是拿到“别人怎么听你说话”的真实反馈。
- **每周一次 10 分钟录屏讲解**：对着摄像头讲一个技术点（本周学的），回看并记录：卡顿处、口头禅、说不清的概念。这是提升表达最快的方法，没有之一。

#### 第 4 层｜最后手段（触发条件：连续 3 周完不成周计划）
报一个 **1 万元以内的线上同步班**（如尚硅谷线上同步班）。**报名当天必须继续投简历**，绝不能以“学完再找”为前提。线下脱产班坚决排除。

**失控的正确反应**：连续两周无 commit → **立刻把任务砍小**（例如“今天只让接口返回 hello”），而不是延长学习时间。自律崩塌几乎永远是任务过大造成的。

### 四、技术表达训练（每天 60 分钟，固定动作，90 天不断）

你的表达问题本质是**没有结构化框架 + 没有真实案例**。每天做这四件事：

| 动作             | 时长  | 做法                                                         |
| ---------------- | ----- | ------------------------------------------------------------ |
| **① 费曼复述**   | 20min | 把当天学的一个概念，用“给非技术人员讲”的方式口述录音，不超过 90 秒。回听，删掉所有“然后、就是、那个”。 |
| **② STAR 卡片**  | 15min | 每天写 1 张：情境/任务/行动/结果，带数字。来源：4 年 Java 经历重构 + 当前项目踩坑。90 天积累 90 张 = 面试题库。 |
| **③ 架构图重绘** | 15min | 每天凭记忆画一遍系统架构（从 D30 起），画不出来说明没懂。    |
| **④ 反问清单**   | 10min | 每天准备 3 个能问面试官的问题（业务痛点、技术债、团队结构）。会提问的人被认为“表达清晰”。 |

**每周六加练**：10 分钟录屏讲解（见第三层）。**D30/D60/D90 各写一篇长文公开发布**，这是表达的终极验收。
