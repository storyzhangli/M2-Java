## 4. 核心结论速查

- 一次调用一条终态：三终态互斥，AtomicBoolean CAS 防重复，观测覆盖全部重试但只写一条。

- 延迟真实：durationMs/TTFT 基于单调时钟，未发射分片则 TTFT 缺省。
- Token 可信：原生 usage 优先，缺失留 null 并给状态/来源，total 严格推导，流式只覆盖不相加。
- 安全：无硬编码真实密钥，白名单从结构上排除 Key/Authorization/Cookie/完整 Prompt/响应。
- 契约零破坏：路径、方法、DTO、HTTP 统一 200、业务码、SSE 事件保持不变；测试 68/68 通过。
