## 阶段 A 骨架扫描

- 确认 D15 父 POM 为 packaging=pom，仅含 D15_FOPF 一个模块。
- 模块实际依赖：spring-boot-starter-web、validation、aop、spring-ai-starter-model-deepseek、lombok、starter-test；**无数据库/ORM/Redis/安全框架**，据此确定“种子 JSON + ConcurrentHashMap 内存仓库”的最小持久化方案，Repository 接口化保留替换空间。
- 盘点既有资产：统一 Result/ResultCode、GlobalExceptionHandler（IllegalArgumentException 归一 4001）、D14 SSE 双层超时、sse-parser.js、13 个既有测试类。
- 过程记录：`docs/temp_docs/D15-scan-and-design.txt`。

## 阶段 B 技术预研与设计

- 用独立 javac/java 探针实测 Spring AI 1.1.8 的 PromptTemplate 行为（jshell 在本机有 NoClassDefFound 异常，改用编译运行）：
  - 默认单大括号 `{ }` 分隔；
  - 裸 JSON 大括号在 THROW/NONE 模式均抛 `The template string is not valid`；
  - 缺变量抛 IllegalStateException 且消息含 Missing variable names；
  - `\{` `\}` 可输出字面大括号。
- 据此定规则：占位符必须先声明、字面括号必须转义、保存期桩值试渲染。
- 探针源码与输出：`docs/temp_docs/D15StProbe.java`、`D15-st-probe-out.txt`；依赖 classpath：`D15-cp.txt`（109 个 jar）。

## 阶段 C 编码

### C1 模板管理

- 新增 `prompt` 包：model（4 个）、dto（3 个）、Repository 接口 + 内存实现、Validator、Service、Controller。
- 新增种子资源 `prompt-templates/seed-templates.json`，6 个场景；code_review 的 JSON 示例按 ST4 规则转义。
- 管理能力：列表（场景/状态/关键字过滤）、详情、创建、更新（版本自增）、启停、逻辑删除、`/roles` 角色清单。

### C2 双角色会话

- 新增 `conversation` 包：Message/Session/Memory/RoleConversationService；容量 500 会话 × 20 条。
- 新增 `ChatInvocation`，AiChatService 增加两个 default 重载保证旧测试零改动；Mock 覆写为确定性回显，DeepSeek 覆写按 System→历史→当前 User 顺序组装消息。
- ChatRequest 增加可选 scene/sessionId/variables；同步 ChatController 与流式 ChatStreamController 分别接线；SSE start 帧加溯源字段并用 NON_NULL 保持旧帧形态；失败/超时/断连三条路径统一回滚用户消息。

### C3 前端

- index.html/app.js 增加角色选择器、会话提示、新对话重置；新建 templates.html/templates.js 管理页；app.css 追加管理页样式；全部远程文本 textContent 渲染。

## 阶段 D 验证（含一次真实失败与修复）

1. 首次 `mvn compile`：通过。
2. 首次 `mvn test`：**失败 2 个**，均为既有日志测试（AccessLogIntegrationTest、AccessLogRealContainerTest），缺少 CONTROLLER_ACCESS 事件。

7. `mvn package -DskipTests`：生成 `D15_FOPF-1.0-SNAPSHOT.jar`（38,432,459 字节）。
8. mock 模式真机启动（PID 记录于 temp_docs），执行 `D15-collect-evidence.ps1`：
